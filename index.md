# lighthouse

The lighthouse package includes various utility functions used by staff
at the [Lighthouse
Institute](https://www.chestnut.org/lighthouse-institute/), a division
of Chestnut Health Systems.

## Installation

Install the lighthouse package by running:

``` r
## git2r is needed only if Git isn't installed on your system
# install.packages(c("git2r", "remotes"))
remotes::install_github("ccsarapas/lighthouse")
```
