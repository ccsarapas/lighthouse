# US federal holidays over a 20-year period

A dataset containing dates of United States federal holidays from
2010-12-31 through 2030-12-31.

## Usage

``` r
holidays_us
```

## Format

A tibble with 212 rows and 2 variables:

- Date:

  date holiday observed

- Holiday:

  holiday name

## Source

<https://www.opm.gov/policy-data-oversight/pay-leave/federal-holidays/>
